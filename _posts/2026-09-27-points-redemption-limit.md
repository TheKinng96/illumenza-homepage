特典の設定画面には「交換回数制限」という項目があります。

名前から「クーポンを何回使えるか」の設定だと思われがちですが、そうではありません。**交換回数制限は、1人の会員が同じ特典を何回交換できるか**を決める設定です。

この記事では、よく混同される2つの「回数」の違いと、交換回数制限をオフ・オンにしたときの動きを順に説明します。

## 「回数」は2種類あります

マイルの交換には、性質の違う2つの回数が関わっています。

| | クーポンの利用回数 | 交換回数制限 |
| --- | --- | --- |
| 何の回数か | 発行された1枚のクーポンを、お買い物で使える回数 | 1人の会員が、同じ特典をマイルと交換できる回数 |
| 決まり方 | 常に1回。設定では変えられません | 特典ごとに設定します。オフなら制限なし |
| 数えるタイミング | お買い物でクーポンを使ったとき | 会員がマイルを交換したとき |

設定画面で決められるのは、右側の「交換回数制限」だけです。

## 交換するたびに、新しいクーポンが1枚発行されます

限定特典とショップポイント交換を除く特典は、会員がマイルと交換した時点でクーポンが1枚発行されます。クーポンには一意のコードが割り当てられ、**お買い物で使えるのは1回だけ**です。

同じ特典をもう一度交換すると、別のコードを持つ新しいクーポンがもう1枚発行されます。1枚のクーポンを何度も使えるようになるわけではありません。

クーポンの発行の仕組みやクーポン名の初期値については、[交換したクーポンは1回限り](/blog/points-coupon-issuance/)で詳しく説明しています。

## 交換回数制限は「同じ特典を何回交換できるか」

交換回数制限をオンにすると、「最大交換回数」の欄が表示されます。ここに入れた回数が、1人の会員がこの特典を交換できる上限です。

       loading="lazy" decoding="async">
  <figcaption>オンにすると、最大交換回数を入力できるようになります。</figcaption>
</figure>

たとえば「1,000円引きクーポン」を「1回まで」にした場合は、次のようになります。

- 会員は、この特典を1回だけ交換できます
- 交換したあとは、発行されたクーポンを使ったかどうかに関係なく、同じ特典はもう交換できません
- 他の特典の交換には影響しません
- 上限は会員ごとに数えます。ある会員が上限に達しても、他の会員は交換できます

制限は期間でリセットされません。「1回まで」なら、その会員にとってはずっと1回までです。

## オフにすると、何度でも交換できます

交換回数制限をオフにすると、回数の制限はなくなります。設定画面にも「制限なし：1人の会員が何度でも交換できます」と表示されます。

<figure>
  <img src="/images/blog/points-redemption-limit/limit-off.webp"
       alt="特典の設定画面の交換回数制限。スイッチがオフになっており、「制限なし：1人の会員が何度でも交換できます」と表示されている。"
       loading="lazy" decoding="async">
  <figcaption>オフのときは、回数の制限がないことが画面に表示されます。</figcaption>
</figure>

オフでも、交換するたびに必要マイル数が差し引かれ、1回だけ使えるクーポンが1枚ずつ発行されます。マイルが足りていれば、会員は同じ特典を何度でも交換できます。

## 会員のパネルでの見え方

交換回数制限を設定した特典には、パネルの特典一覧で「1回まで」のように上限が表示されます。

上限まで交換した会員には、その特典が「1回まで・交換済み: 交換した日付」と表示され、交換できなくなります。交換できない特典は、一覧の下のほうに移ります。

## どの交換が「1回」に数えられるか

交換回数は、交換の状態によって数えるかどうかが決まります。

| 交換の状態 | 回数に数えるか |
| --- | --- |
| 保留中（承認待ち） | 数えます |
| 承認済み | 数えます |
| 完了 | 数えます |
| 使用済み（クーポンがお買い物で使われた） | 数えます |
| 却下 | 数えません |
| 期限切れ（承認されないまま期限を過ぎた） | 数えません |
| 失敗 | 数えません |

承認待ちの交換も1回に数えます。そのため、承認を待っている間に同じ特典を何度も申請して、上限を超えることはできません。

一方、ショップが却下した交換や、承認されないまま期限切れになった交換は数えません。会員はもう一度その特典を交換できます。

## 回数を0や空欄にしたまま保存すると

交換回数制限をオンにしたまま、最大交換回数を空欄や0にして保存しようとすると、次のメッセージが表示されて保存できません。

<figure>
  <img src="/images/blog/points-redemption-limit/error-toast.webp"
       alt="赤いエラー表示。「交換回数制限: 1以上の回数を入力してください。回数を制限しない場合は、交換回数制限をオフにしてください。」と書かれている。"
       loading="lazy" decoding="async">
  <figcaption>オンにしたときは、1以上の回数が必要です。</figcaption>
</figure>

回数を制限したくない場合は、「0回」にするのではなく、**交換回数制限をオフ**にしてください。オフにすれば、最大交換回数の欄に何が入っていても、そのまま保存できます。

## まとめ

- 交換回数制限は、**1人の会員が同じ特典を何回交換できるか**の設定です
- 交換のたびに発行されるクーポンは、交換回数制限の有無にかかわらず**1回しか使えません**
- **オフなら制限なし**です。マイルが足りていれば、同じ特典を何度でも交換できます
- オンにした場合は、最大交換回数に**1以上**を入れます。制限しないなら、0ではなくオフにします
- 保留中・承認済み・完了・使用済みの交換は回数に数え、却下・期限切れ・失敗は数えません
