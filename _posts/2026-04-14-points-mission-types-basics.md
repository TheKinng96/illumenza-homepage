マイル制度を「購入金額の○%を付与する」だけで設計すると、お客様との接点は購入時に限られます。買っていない期間には、ショップとお客様をつなぐきっかけがありません。

ミッション機能を使えば、マイルを付ける「きっかけ」を購入以外にも広げられます。この記事では、ミッションの**種類・頻度・受け取り方**の3つの軸から、設計の考え方を整理します。

## きっかけは大きく3種類

会員ステージで設定できるミッションは、内容によって大きく3つのグループに分けられます。

| グループ | 例 |
| --- | --- |
| 購入・アカウント | お買い物ミッション、誕生日ミッション、登録プレゼント |
| SNS | Instagram・Facebook・X・TikTok のフォロー、YouTube チャンネル登録、LINE 友だち追加、Facebook ページいいね、X でシェア |
| コンテンツ | 商品レビュー、カスタム（繰り返し可） |

管理画面では、ミッションの名前・種類・獲得マイルを指定して、一覧に並べて管理します。

3つのグループには、それぞれ違う役割があります。

購入系は売上につながりますが、購入がなければ発生しません。SNS系は一度きりで終わるものが多い一方、購入前のお客様にも参加してもらえます。コンテンツ系は、商品レビューのように「買ったあと」の行動を促せます。

## 頻度で「続くか、一度きりか」を決める

同じミッションでも、設定する頻度によって役割が変わります。

| 頻度 | 向いている使い方 |
| --- | --- |
| 一回きり | 会員登録、SNSフォローなど、繰り返しようがないもの |
| 繰り返し可 | 回数を問わず何度でも達成できるもの |
| 毎日 | 来店・ログインの習慣づけ |
| 毎週 | 毎日来るほどではないショップ向け |
| 毎月 | 誕生月・記念月のような月単位の施策 |

「毎日」を設定すると、ショップを訪れる習慣はつきやすくなります。その一方で、マイルの発行量も毎日増えていきます。

そのため、頻度を決めるときは、必要な原資もあわせて計算しておくことが大切です。たとえば、毎日10マイルを付与するミッションを1年間続けると、1人あたり最大3,650マイルになります。

## 自動で付けるか、お客様に受け取ってもらうか

マイルの受け取り方は、2つのモードから選べます。

**自動付与**では、条件を満たした時点でマイルが加算されます。お買い物ミッションのように、達成したことをシステム側で確認できるミッションに向いています。

**タップして受け取る**では、お客様が自分で受け取り操作をした時点でマイルが加算されます。SNSフォローのように、ショップ側で達成したかどうかを機械的に確認しづらいミッションに使います。

タップして受け取るミッションには、管理者の承認を必須にする設定もあります。

承認制にすると、不正な受け取りを減らせます。一方で、ショップ側には申請内容を確認する作業が発生します。承認待ちが溜まったままになると、お客様からは「申請したのに何も起きない」ように見えてしまいます。

設定するときは、**実際に運用できる件数かどうか**を先に考えることが大切です。

## ステージで出し分ける

ミッションには、「このステージ以上の会員だけに表示する」という条件も設定できます。

上位ステージの特典を、割引ではなく「参加できるミッションが増える」という形で用意することもできます。これなら、マイルの原資を増やさずに、会員ステージごとの差をつけられます。

## 設計の順番

決める順番を間違えると、あとから制度全体を見直すことになりかねません。次の順番で考えると、手戻りを減らせます。

1. **交換先を先に決める**。何マイルで何と交換できるのかを決めます。交換先が決まっていないと、1マイルの価値も定まりません。
2. **購入ミッションの付与率を決める**。ここがマイルの原資の中心になります。
3. **購入以外のミッションを足す**。ここで初めて、SNSやレビューなどを検討します。
4. **頻度と受け取り方を決める**。マイルの原資と、ショップ側の運用負担は、主にこの段階で決まります。

購入以外のミッションから先に決めると、無料で配るマイルだけで交換先に届いてしまうことがあります。

そうなると、「買わなくても特典が手に入る」制度になってしまいます。

## まとめ

ミッションは、**購入以外の接点をつくる**ための機能です。

ただし、きっかけを増やすほど、発行するマイルも増えていきます。

ミッションの種類を増やす前に、まず交換先と原資を決めておくことが大切です。先に全体を設計しておけば、あとから還元率を下げる——お客様にとって特に印象の悪い変更——を避けやすくなります。
