ルーレットの見た目は、設定したテーマによって変わります。用意されているのは11種類で、そのうち10種類は日本の行事に合わせたテーマです。

## 用意されているテーマ

デフォルトのほかに、お正月、バレンタインデー、ホワイトデー、ゴールデンウィーク、こどもの日、七夕、お盆、ハロウィン、ブラックフライデー、クリスマスがあります。

日本のECで使いやすいように、日本の行事に合わせたテーマが揃っています。海外製のツールで見かけるような、日本ではあまり馴染みのない行事のテーマはありません。

## 切り替える時期

季節のテーマは、切り替えるタイミングが大切です。早すぎても季節感が出にくく、遅すぎると行事が終わったあとまで表示されてしまいます。目安は次のとおりです。

| テーマ | 切り替える時期 |
| --- | --- |
| お正月 | 12月下旬〜1月中旬 |
| バレンタインデー | 1月下旬〜2月14日 |
| ホワイトデー | 2月中旬〜3月14日 |
| ゴールデンウィーク | 4月中旬〜5月上旬 |
| こどもの日 | 4月下旬〜5月5日 |
| 七夕 | 6月下旬〜7月7日 |
| お盆 | 8月上旬〜中旬 |
| ハロウィン | 10月上旬〜31日 |
| ブラックフライデー | 11月中旬〜下旬 |
| クリスマス | 12月上旬〜25日 |

**行事が終わったら、テーマも元に戻してください。** たとえば、12月26日になってもクリスマスのルーレットが表示されていると、更新されていない印象を与えます。

季節テーマのよさは、「今、この行事をやっている」という雰囲気を出せることです。ただし、行事が終わると、その効果が逆に働くことがあります。

## 切り替えないほうがよい場合

テーマを変更すると、色もテーマに合わせた配色に切り替わります。ブランドカラーに合わせて色を細かく調整していた場合、その設定は上書きされます。

**ブランドの世界観を優先するショップは、デフォルトのまま色だけを整える方法もあります。** 高価格帯の商材を扱うショップや、落ち着いた雰囲気を大切にしたいショップでは、行事のたびに見た目が変わるよりも、いつも同じデザインのほうが自然な場合があります。

季節テーマと相性がよいのは、行事と商材の結びつきが強いショップです。ギフト需要のある商材、家族向けの商材、季節によって消費が変わる商材などが該当します。

## 運用の手間を見積もる

10種類の行事すべてに対応すると、年間で10回の切り替え作業が必要になります。その分、切り替え忘れのリスクも増えます。

現実的には、**自分のショップで売上が伸びる行事を2〜3つ選ぶ**くらいがちょうどよい運用です。すべての行事に対応する必要はありません。

## テーマと当選内容は別です

テーマで変わるのは、ルーレットの見た目です。クーポンの内容や当選確率は変わりません。

行事に合わせて特典の内容も変えたい場合は、キャンペーン自体を分けてください。テーマだけを変えて、クーポンの内容は通年と同じままにすると、見た目と内容が合わなくなることがあります。

## テーマを変えても中身は変わりません

テーマを変更しても、変わるのは見た目だけです。当選確率やクーポン、フォームの文言はそのまま残ります。

季節に合わせて特典の内容も変える場合は、キャンペーンを複製して作ってください。見た目はクリスマスなのに、当たるクーポンは通年と同じという状態では、季節感が見た目だけになってしまいます。

## まとめ

11種類のテーマは、日本の行事に合わせて用意されています。テーマを切り替えたら、行事が終わったあとに元へ戻すところまでが一連の作業です。

すべての行事に対応する必要はありません。ショップで売上が伸びる行事を2〜3つ選ぶ方法もあります。ブランドの一貫性を優先したい場合は、デフォルトのまま使っても問題ありません。
