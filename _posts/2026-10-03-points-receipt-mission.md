**レシート登録**は、実店舗でのお買い物にマイルを付けるためのミッションです。

オンラインショップの注文は、カラーミーショップから自動で本アプリに届き、お買い物ミッションでマイルが付与されます。一方、店頭のレジで支払ったお買い物の情報は、本アプリには届きません。レシート登録では、お客様が店頭で受け取ったレシートをスマートフォンで撮影して申請し、その合計金額をもとにマイルを受け取ります。

レジ（POS）との連携は必要ありません。この記事では、お客様の流れから、管理画面で決める設定、料金までを順に説明します。

## お客様の流れ

お客様の操作は次のとおりです。レシート登録を使うには、会員登録が必要です。

1. ショップのパネルを開き、マイルミッションの一覧から**「レシート登録」**を選ぶ
2. **「レシートを撮影する」**を押す。カメラの画面が別のタブで開きます
3. レシートを撮影する。長いレシートは上部と下部の2枚に分けて撮れます。2枚で撮っても申請は1件です
4. AIがレシートから店舗名・日時・合計金額・レシートNo.・登録番号を読み取る
5. 読み取った内容と獲得予定のマイルを確認して、**「この内容で申請する」**を押す
6. 「ショップに戻る」でショップの画面に戻る

カメラが使えないブラウザでは、「写真から選ぶ」から撮影済みの写真を選ぶこともできます。

### 撮影のコツ

撮影画面では、次の3か所が写るように案内が表示されます。

| 場所 | 写す内容 |
| --- | --- |
| ① 上部 | 店舗名・日時 |
| ② 合計金額 | お支払いの合計 |
| ③ 下部 | レシートNo.・登録番号 |

平らな場所に置き、影が入らないように撮るのがコツです。

合計金額と、レシートNo.または日時が読み取れないと申請できません。その場合は、撮り直しの理由（「ピントが合っていません」「合計金額が読み取れません」など）が表示されます。1日に3回読み取れなかったときは、店舗スタッフに問い合わせるよう案内されます。

読み取った金額や日時が実際と違うときは、お客様が確認画面で修正できます。修正した申請は、自動ではマイルが付与されず、ショップの確認に回ります。

## マイルの付与率はお買い物ミッションと同じです

レシート登録には、独自の付与率がありません。**レシートの合計金額に、お買い物ミッションの設定をそのまま当てはめて**マイルを計算します。

- 「¥100ごとに10マイル」のような付与率
- 最低金額（下回るレシートはマイル付与の対象外で、申請できません）
- 注文金額による倍率
- 会員ステージによる倍率
- マイル倍率のキャンペーン（レシートの購入日に開催中のもの）

お買い物ミッションを無効にしていても、レシート登録は同じ設定の付与率を使います。付与率を変えたいときは、お買い物ミッションの設定を変更してください。レシート登録の設定画面にも、現在の付与率と「変更」のリンクが表示されます。

倍率の重なり方は、[マイル倍率は掛け算です](/blog/points-multiplier-stacking/)で説明しています。

## 申請の受け付け

管理画面の「マイルの貯め方」から「レシート登録」を開くと、受け付けの条件を設定できます。

| 項目 | 初期値 | 設定できる範囲 |
| --- | --- | --- |

## 自動承認と、確認が必要な申請

**自動承認**がオンのときは、合計金額が**自動承認の上限金額（初期値¥5,000）以下**で、次の警告がひとつもない申請に、すぐマイルが付与されます。

警告がある申請は自動承認されず、ショップの確認に回ります。

| 確認事項として表示される内容 | 確認に回る理由 |
| --- | --- |
| 自動承認の上限を超えています | 合計金額が上限金額を超えている |
| 金額が一致しません | お客様が入力した金額と、読み取った金額が違う |
| 日時が一致しません | 入力された日時と、読み取った日時が10分以上違う |
| 日時を読み取れませんでした（入力値を使用） | 読み取れなかったため、お客様が入力した日時を使っている |
| 同じ日時・金額または同じ画像の申請あり | 重複の可能性がある |
| 他店のレシートの可能性 | 登録番号が、ショップで設定したものと違う |
| レシートNo.なし | レシートNo.が読み取れなかった |

自動承認をオフにすると、すべての申請がショップの確認に回ります。

確認に回った申請は、管理画面の**「承認待ち」**の**「レシート登録」**タブに並びます。確認待ちの申請があると、ショップにもメールでお知らせします。

承認または自動承認されると、お客様にはパネルのお知らせとメールで連絡が届きます。

承認したあとに返品があった場合は、会員の詳細画面の「レシート登録」タブから**「マイルを取り消す」**ができます。

承認待ちの画面全体の使い方は、[承認待ちを1つの画面で捌く](/blog/points-approvals-queue/)でも紹介しています。

## インボイス登録番号で、他店のレシートを見分ける

設定画面の**「インボイス登録番号（任意）」**に、ショップの登録番号（Tから始まる13桁の数字、例：T1234567890123）を入れておくと、レシートに印字された登録番号と照らし合わせます。

番号が違うレシートは「他店のレシートの可能性」として、自動承認せずに確認に回します。空欄のままでも使えますが、他店のレシートで申請される心配がある場合は入力しておくと安心です。

## 同じレシートは二度申請できません

レシートNo.・日付・金額が同じレシートは、同じものとして扱います。すでに申請済みのレシートを申請すると、お客様には**「このレシートは既に申請済みです」**と表示され、申請は受け付けられません。

別の会員が同じレシートを申請しようとした場合も、同じ表示になります。お客様に、先に申請した会員が誰かは表示しません。

ショップ側では、こうした申請も記録されます。別の会員のレシートを申請しようとした会員には、会員の詳細画面に「他の会員のレシートを申請 ○件」と表示され、ショップにメールでお知らせします。

## 読み取り件数と料金

レシートをAIで読み取った件数を**レシート読み取り**として数えます。毎月、プランごとに無料で使える件数があります。

| | 内容 |
| --- | --- |
| 無料で使える件数 | ベースプラン 月500件／拡張プラン 月1,000件 |
| 数え直し | 毎月1日にリセット |
| 無料の件数を超えた分 | 100件ごとに¥110（税込） |
| 月の上限 | ¥11,000（税込）まで |
| 請求のタイミング | 翌月の請求にまとめて請求 |

1件の申請を1件と数えます。2枚に分けて撮影しても1件です。重複のため受け付けなかった申請と、読み取れずに撮り直した分は数えません。

今月の件数は、レシート登録の設定画面の**「今月の読み取り」**で確認できます。無料の件数の80%と100%に達したときにも、メールでお知らせします。

## カウンター用ポスター

店頭でお客様に知ってもらうために、レジ横に置けるA4のポスターを印刷できます。設定画面の**「ポスター」**の**「印刷する」**から開き、「このポスターを印刷する」を押します。

ポスターのQRコードをお客様がスマートフォンで読み取ると、ショップのページが開き、パネルがレシート登録の画面で開きます。会員登録がまだのお客様には、先に会員登録の案内が表示されます。

## まとめ

- レシート登録は、店頭で受け取ったレシートを撮影して申請し、マイルを受け取るミッションです。レジとの連携は不要です
- 付与率は**お買い物ミッションと同じ**です。最低金額や各種の倍率も同じく適用されます
- 申請期限は**購入から7日以内**、上限は**1日3枚まで**が初期値です
- 自動承認は**¥5,000以下で警告のない申請**だけです。それ以外は「承認待ち」のレシート登録タブで確認します
- 同じレシートは二度申請できません。別の会員による申請はショップにお知らせします
- 無料で使える読み取りは**月500件（ベースプラン）／月1,000件（拡張プラン）**、超えた分は100件ごとに¥110（税込）、月¥11,000（税込）までです
