この記事は、設定項目の説明ではありません。**ひとつのショップを最後まで組み立てて、途中で矛盾を見つけるまで**をやります。

数字はすべて**仮のもの**です。実在のショップの数字ではありません。見てほしいのは値ではなく、**どの数字が他のどれを決めているか**です。

## 前提

| 項目 | 値 |
| --- | --- |
| 平均注文額 | 5,000円 |
| 還元率 | 1%（100円で1pt） |
| 購入頻度 | 年4回 |

**1回の購入で50pt**、年間で200pt。ここが基準です。

## ① 無料で貯まる分を数える

買わずに貯まる合計を先に出します。

| ミッション | pt |
| --- | --- |
| 会員登録ポイント | 100 |
| アンケートに回答 | 100 |
| Instagramフォロー | 100 |
| **合計** | **300** |

**無料で300pt**。これが「1円も使わずに届く上限」です。

## ② 交換先を「購入回数」で決める

ここでよくある失敗は、**500pt・1,500pt・5,000pt のようにキリのいい数字から決めること**です。キリがいいだけで、根拠がありません。

先に**何回買った人に渡したいか**を決めて、あとからptに直します。

| 段 | 渡したい相手 | 計算 | 必要pt |
| --- | --- | --- | --- |
| 入口 | 4回買った人 | 300 + 50×4 | **500** |
| 中間 | 10回買った人 | 300 + 50×10 | **800** |
| 上位 | 20回買った人 | 300 + 50×20 | **1,300** |

半端な数字になりますが、**これは届く数字**です。1,500ptにした瞬間に「24回」になり、年4回の店では6年かかります。

## ③ ここで有効期限と突き合わせます

さて、有効期限を1年に設定したとします。よくある設定です。

ここで問題が起きます。[有効期限は各ポイントの獲得日から起算](/blog/points-expiry-settings/)されるので、**手元に残るのは直近1年分だけ**です。

| 有効期限 | 保有できる上限 |
| --- | --- |
| 1年 | 初年度500pt、**2年目以降は200pt** |
| 2年 | 初年度700pt、以降400pt |
| 3年 | 初年度900pt、以降600pt |

**1年の期限をつけた時点で、800ptの中間段も1,300ptの上位段も、誰も到達できません。**古い分から失効していくので、残高がそこまで積み上がらないのです。

無料の300ptも1年で消えるため、2年目以降は年200ptが上限になります。入口の500ptにすら届きません。

## ④ どう直すか

3つしかありません。

1. **有効期限を延ばす**（または設けない）。上位段を残したいならこれです。
2. **交換先を下げる**。期限1年なら、上限は実質200〜500ptです。
3. **1回あたりのptを増やす**。還元率を上げるか、繰り返し可能なミッションを足します。

この店では、期限を**2年**にして、交換先を**500 / 800**の2段に絞るのが素直です。1,300ptの段は、期限のあるポイントでは維持できません。

限定特典のような上位の枠を置きたいなら、**そこだけ別に設計する**ことになります。

## ⑤ ランクは別の数え方です

ここで救いがあります。ランクの**アクティビティポイントは累計**で、有効期限で減るポイント残高とは別の数え方です。

つまり、**残高は失効しても、ランクは上がり続けます**。だから期限を短くした店ほど、報いる仕組みはランク側に寄せることになります。

| ランク | しきい値 | 到達 |
| --- | --- | --- |
| ブロンズ | 0 | 全員 |
| シルバー | 600 | 6回・約1.5年 |
| ゴールド | 1,050 | 15回・約3.75年 |

## 数字のつながり

**平均注文額 → 1回あたりのpt → 無料で貯まる分 → 交換先（購入回数から逆算） → 有効期限（ここで交換先を検算） → ランク**

大事なのは最後から2番目です。**交換先を決めたあと、必ず有効期限と突き合わせてください。**この2つは別々の画面にあるので、突き合わせないまま公開されます。

## そのまま使わないでください

平均注文額が5万円なら1回500ptなので、同じ500ptの交換先は**1回で届きます**。置き換えるのは数字ではなく**手順**です。

無料分を数える → 購入回数から交換先を決める → 有効期限で検算する → ランクを別に置く。順番だけが、どの店でも同じです。

## まとめ

交換先の上段が機能するかどうかは、交換先の設定ではなく**有効期限**が決めています。期限を短くするほど、到達できる残高の上限は下がります。キリのいい数字から決めず、購入回数から決めて、最後に期限で検算してください。
