設定項目ごとの説明ではなく、**ひとつのショップを最後まで組み立てて、途中で矛盾を見つけるまで**をやります。

数字はすべて**仮のもの**です。実在のショップの数字ではありません。見てほしいのは値ではなく、**どの数字が他のどれを決めているか**です。

## 前提

| 項目 | 値 |
| --- | --- |
| 平均注文額 | 5,000円 |
| 還元率 | 1%（100円で1pt） |
| 購入頻度 | 年4回 |
| **有効期限** | **1年** |

有効期限を先に置くのがポイントです。**1年が扱いやすい既定値**です。これより短いと失効ばかりになり、長いと未使用ポイントが積み上がって、いつまでも負債として残ります。

そして1年に決めた時点で、**設計できる範囲がほぼ確定します。**

## ① 1年で貯まる分を数える

有効期限が1年なら、[ポイントは獲得日から1年で消える](/blog/points-expiry-settings/)ので、**手元に残るのは常に直近1年分だけ**です。だから数えるべきは総額ではなく**年間の獲得額**です。

| 内訳 | pt / 年 |
| --- | --- |
| 購入（5,000円 × 年4回 × 1%） | 200 |
| 商品レビュー（100pt × 年2回） | 200 |
| **年間合計** | **400** |

これに加えて、**初年度だけ**入るものがあります。

| 一度きり | pt |
| --- | --- |
| 会員登録ポイント | 100 |
| アンケートに回答 | 100 |
| Instagramフォロー | 100 |

一度きりの300ptは、1年経てば消えます。**2年目以降の上限は400pt**です。

## ② 交換先は「400pt」ひとつだけ

年間400ptと分かれば、置ける交換先は自動的に決まります。

| 候補 | 判定 |
| --- | --- |
| 300pt | **不可**。一度きりのミッションだけで届く。買わずに交換できてしまう |
| **400pt** | **これ**。毎年1回、確実に届く |
| 500pt | 初年度は届くが、2年目以降は届かない |
| 800pt | 誰も届かない |

**500ptと800ptは、置いても存在しないのと同じ**です。設定画面には並びますが、交換されることはありません。

多段の交換先が欲しくなりますが、有効期限1年でそれをやるには、年間の獲得額そのものを増やすしかありません。**還元率を上げるか、繰り返せるミッションを足すか**です。段だけ増やしても届きません。

## ③ 届かない分はランクに寄せます

ここが大事なところです。ランクの**アクティビティポイントは累計**で、有効期限で減る残高とは**別の数え方**です。

つまり、**残高は毎年リセットされても、ランクは上がり続けます。**

| ランク | しきい値 | 到達 |
| --- | --- | --- |
| ブロンズ | 0 | 全員 |
| シルバー | 800 | 2年目 |
| ゴールド | 2,000 | 5年目 |

長く続けている人に報いる役目は、**交換先ではなくランクが担います**。有効期限を1年にした店ほど、この分担がはっきりします。

## ④ ランクに何を置くか

そしてここで、割引から離れます。

400ptの交換先は「小さなお礼」です。それでいいのです。**ロイヤルティ制度の目的は、値引きの上乗せではありません。**続けて買ってくれた人、レビューを書いてくれた人に、**貢献が見えていると伝えること**です。

ランクの[限定ミッションや限定交換オプション](/blog/points-rank-benefits/)には、値引きで代えられないものを置いてください。先に知らせる、直接相談できる、名前が残る。原価は小さく、上位ほど価値が出ます。

## 数字のつながり

**有効期限1年 → 年間の獲得額 → 交換先（1段） → 届かない分はランク → ランクには値引き以外**

左端が有効期限であることに注意してください。**先に期限を決めると、交換先は計算で出ます。**逆に交換先から決めると、期限と噛み合っているかを誰も検算しません。

## そのまま使わないでください

平均注文額が5万円なら1回500ptなので、年4回で2,000pt貯まります。同じ手順で計算すると、交換先は2,000pt前後になります。**数字ではなく手順を移してください。**

① 年間の獲得額を数える → ② その額の交換先を1つ置く → ③ 一度きりのミッションだけで届かないか確認 → ④ 残りをランクに寄せる。

## まとめ

有効期限を1年にすると、交換先は**年間の獲得額とほぼ同額**で1つに決まります。それ以上の段は、置いても到達されません。長期の貢献に報いるのはランク側の仕事で、そこに置くものは値引きでなくてかまいません。むしろ、**値引きでないほうが続きます**。
