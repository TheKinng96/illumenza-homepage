## 守るべき声

- **短く言い切る。** 1文は40〜60字を目安に
- **失敗や原因をぼかさない。**「こちらの対応漏れです」と書けるなら、そう書く
- 抽象語より具体的な数字
- 敬体。ただし丁寧すぎて回りくどくしない

## 最重要：直しすぎない

元の記事は日本語として概ね成立しています。**不自然な箇所だけ**を直してください。

- すでに自然な文は、**一字も変えない**
- 全文を書き直す必要はありません。多くの文はそのまま残るはずです
- ただし、**何も直さないのも違います。** 目安として、地の文の2〜4割には手が入るはずです。
  読み返して引っかかる文が1つもない記事は、まずありません
- 言い換えのための言い換えをしない
- **文字数を増やさない。** 元より長くなったら、それは水増しです

避ける表現：

- 「〜することができます」（→「〜できます」）
- 同じ動詞の連発（「確認できます」「確認します」を何度も使わない）
- 「〜していきましょう」「スムーズです」などのぼかし
- 同じ語尾の3連続（〜ます。〜ます。〜ます。）

## 置き換え禁止（言い切りを弱めない）

次の方向の書き換えは、すべて改悪です。絶対にしないでください。

| 元の表現 | してはいけない書き換え |
| --- | --- |
| 出ます / 出る | 表示されます |
| 違います | 異なります |
| 楽です | しやすくなります |
| 目の前に出ます | 画面の中央に出ます |
| 邪魔にしかなりません | 邪魔になります |
| 〜するしかありません | 〜する必要があります |
| こちらの対応漏れです | 対応が完了していません |
| 順番として早すぎます | まだ早いです |

原則：

- **言い切りを弱めない。**「〜しかありません」「〜だけです」「〜にしかなりません」は
  そのまま残す
- **ヘッジを足さない。**「ことが多い」「ことがよくあります」「場合があります」を
  新たに付け足さない
- **和語を漢語に置き換えない。**（違う→異なる、楽→容易、出る→表示される）
- **具体的な言葉を一般的な言葉にしない。**（目の前→画面の中央）
- 元の文のほうが短くて強いなら、**元の文が正しい**

この記事は、わざと短く・強く書いてあります。丁寧で滑らかなビジネス日本語に
均すことは、この仕事では改悪です。迷ったら、直さないでください。

## 進め方

1. まず記事を最初から最後まで通して読み、全体の流れをつかむ
2. そのうえで、**一本の文章として**整える

一文ずつ置き換える作業ではありません。段落をまたぐつなぎ、話の運び、
読み終えたときのリズムまで含めて見てください。同じ見出しの中であれば、
段落を分けても、つなげても、順番を入れ替えてもかまいません。

記事の冒頭から末尾まで同じ声で、かつ他の記事と並べても同じ書き手だと
わかるように整えてください。

## やらないこと

- 内容・理論・数字・手順の正しさは**一切検討しない**。事実確認も改善提案も不要
- 見出しの数・順序・階層は変えない
- front matter（先頭の --- 〜 --- ）は1文字も変えない
- HTMLタグ・画像パス・表の行・リンクは変えない
  （alt と figcaption の**文**だけは自然さのために直してよい）
- HTMLの**属性を足さない・消さない**。`loading="lazy"` や `decoding="async"` を
  補わないでください。揃っていないように見えても、それは意図的です
- 日本語の文章だけを見てください。マークアップの改善は仕事ではありません
